# 파워포인트 산출물

작업은 `scripts/pptx_tool.py` 로 하고, 쪽 그림 확인은 플러그인 공용 `../../scripts/render.py` 로 한다(둘 다 이 SKILL.md 가 있는 폴더 기준. 다른 작업 폴더에서는 절대 경로로 부른다).
필요한 것: Python 3 · `python-pptx` · `Pillow`. 없으면 `python -m pip install python-pptx Pillow` 를 알리고 멈춘다.

## 템플릿이 있을 때 (먼저 고른다)

1. `python scripts/pptx_tool.py inspect <템플릿>` 으로 슬라이드(`s2`) · 도형 id(`s2.#5`, 그룹 안 도형도 같은 꼴) · 표 칸(`s2.#5.r1.c0`) · 차트 항목과 값 · 메모를 본다.
2. 슬라이드마다 어떤 견본 슬라이드를 본뜰지 정한다. 표지 · 목차 · 본문 · 표 · 차트 같은 꼴이 견본에 하나씩 있으면 그것을 복제해 늘린다.
3. 넣을 글을 다 정하고 다듬은 뒤 spec JSON 을 시스템 임시 폴더에 쓰고 `python scripts/pptx_tool.py fill <템플릿> <spec> <결과>`. 파일에는 한 번만 넣는다.
   fill 은 글을 넣은 도형 가운데 **상자를 넘칠 것 같은 곳**(넘침 어림)을 바로 알린다.
4. `python scripts/pptx_tool.py verify <템플릿> <결과>` — 아래를 본다. 「다름」 · 「글자」에 하나라도 걸리면 실패(종료 코드 1)다.
   - 슬라이드 크기 · 마스터 · 레이아웃 · 테마가 바이트까지 같은가
   - **글자**: 정수가 아닌 크기 · 템플릿에 없던 크기 · 템플릿에 없던 글꼴 · 자동 맞춤으로 줄어든 상자
   - **견본 글자**: 템플릿 글자가 그대로 남은 도형 · 칸. 고정 문구가 아니면 바꾸거나 지운다. 템플릿이 지난 판이면 이 목록은 「이번에 바꾸지 않은 곳」이다
   - **넘침 어림**: 모든 슬라이드에서 상자를 넘칠 것 같은 글
5. `python ../../scripts/render.py <결과> <새 빈 폴더>` 로 슬라이드 그림을 만들고 Read 로 본다. 상자를 넘친 글 · 겹친 도형 · 견본 그림이 남은 곳이 있으면 고쳐서 3부터 다시 한다(결과 이름은 새로 준다).

```json
{"ops": [
  {"set": "s0.#3", "text": "2026년 11월"},
  {"duplicate": "s2", "as": "d1"},
  {"set": "d1.#2", "text": "남은 일"},
  {"set": "d1.#3", "lines": ["엑셀 서식", {"text": "중간보고 반영", "level": 1}]},
  {"set": "s4.#7.r1.c2", "text": "완료"},
  {"chart": "s5.#4", "categories": ["1월", "2월", "3월"], "series": [{"name": "접수", "values": [5, 7, 9]}]},
  {"image": "s6.#8", "path": "C:/…/capture-01.png", "fit": "contain"},
  {"notes": "d1", "text": "발표자 메모"},
  {"delete": "d1.#9"},
  {"delete": "s7"}
]}
```

- 자리는 늘 템플릿의 번호다. 복제한 슬라이드는 `as` 이름으로 가리킨다. 복제본은 원본 바로 뒤에 놓이고, 같은 원본을 여러 번 복제하면 적은 순서대로 이어진다.
- `lines` 는 줄마다 문단 하나다. 모자라면 마지막 문단을 본떠 늘리고 남으면 지운다 — 글머리 · 들여쓰기가 견본을 따른다.
- `chart` 는 값만 바꾸고 색 · 축 · 글꼴 같은 차트 서식은 둔다. 분산형이면 계열마다 `"points": [[x, y], …]` 를 준다. 견본 수치가 남은 차트를 두지 않는다.
- `image` 는 그림만 갈아 끼운다. `contain`(기본)은 비율을 지켜 상자 안 가운데에 맞추고, `cover` 는 상자를 채우게 가장자리를 자른다. 화면 캡처는 `contain` 으로 둔다 — 잘리면 설명이 가리키는 곳이 사라진다.
- 견본으로만 쓴 슬라이드는 끝에 `delete` 로 지운다.

## 글자 크기 · 글꼴 — 바꾸지 않는다

- **글자 크기는 템플릿이 정한 값을 그대로 쓴다.** `set` 은 견본 글자 묶음의 크기를 이어받으니 따로 정하지 않는다.
- **글이 넘치면 글자를 줄이지 않는다.** 글을 줄이거나, 같은 견본 슬라이드를 하나 더 복제해 나눈다. 0.5pt 씩 줄여 맞추면 슬라이드마다 크기가 조금씩 달라져 문서가 어수선해 보인다(verify 가 실패로 친다).
- 템플릿 상자에 자동 맞춤(「넘치면 글자 줄이기」)이 켜져 있으면 PowerPoint 가 열 때 글자를 몰래 줄인다. 넘침 어림에 걸린 상자는 그대로 두지 말고 글을 줄인다.
- 글꼴을 새로 정하지 않는다. 템플릿 · 테마에 없는 글꼴은 verify 가 실패로 친다.
- 스크립트를 따로 짜서 python-pptx 로 고치더라도 위 규칙은 같다. 크기를 정해야 하면 정수 pt 로, 템플릿에 있는 크기 가운데서 고른다.

## 템플릿이 없을 때

`python scripts/pptx_tool.py new <spec> <결과>` — 16:9 기본 서식으로 만든다(`"wide": false` 면 4:3). 첫 장은 표지이고, 글꼴은 라틴 · 한글 모두 맑은 고딕이다(`font` 로 바꾼다).
본문 크기(`size`)는 슬라이드마다 다르게 주지 말고 한 값으로 둔다 — 정수로 반올림한다. 만든 뒤에도 5를 한다.

```json
{"slides": [
  {"title": "사전검토 현황", "subtitle": "2026년 10월"},
  {"title": "진행 상황", "bullets": ["접수 12건", {"text": "회신 8건", "level": 1}], "notes": "메모"}
]}
```

## 지킬 것

- 템플릿에 덮어쓰지 않는다. 결과 경로에 파일이 있으면 도구가 멈춘다.
- 도구가 다루지 못하는 개체(SmartArt · 수식)를 지우거나 그림으로 바꿔 피하지 않는다. 그대로 두고 결과에 밝힌다.
- 슬라이드 전체를 그림 한 장으로 만들지 않는다 — 받는 사람이 고칠 수 없다.
- 쪽 그림을 그리지 못했으면 결과에 「쪽 그림 확인을 못 했다」고 적는다.
