# 엑셀 산출물

작업은 `scripts/xlsx_tool.py` 로 하고, 쪽 그림 확인은 플러그인 공용 `../../scripts/render.py` 로 한다(둘 다 이 SKILL.md 가 있는 폴더 기준. 다른 작업 폴더에서는 절대 경로로 부른다).
필요한 것: Python 3 · `openpyxl` · `lxml`. 없으면 `python -m pip install openpyxl lxml` 을 알리고 멈춘다.

**템플릿을 openpyxl 로 열어 저장하지 않는다.** 그렇게 저장하면 갑지의 로고 · 그림 · 차트 · 메모가 사라진다. 이 도구의 fill 은 칸 값만 고치고 다른 부분은 바이트 그대로 둔다.

## 템플릿이 있을 때 (먼저 고른다)

1. `python scripts/xlsx_tool.py inspect <템플릿>` 으로 시트 · 병합 · 엑셀 표 · 값이 든 칸(`집계!B3`) · 표시 형식 · 줄바꿈 칸을 본다. 수식은 수식 그대로 보인다.
   큰 시트는 `inspect <템플릿> 집계!A1:H40` 처럼 범위를 주어 나눠 본다.
2. 넣을 값을 다 정한 뒤 spec JSON 으로 시스템 임시 폴더에 쓰고 `python scripts/xlsx_tool.py fill <템플릿> <spec> <결과>`.
   - 줄바꿈 칸에 넣은 글이 행 높이를 넘으면 행을 늘리고 「행 높이」로 알린다. 엑셀은 연 뒤에 행 높이를 스스로 맞추지 않아, 늘리지 않으면 글이 잘려 보인다.
   - 끝에 LibreOffice 로 수식을 계산해 그 값을 넣는다. 넣지 않으면 미리 보기 · docket 이 합계 칸을 빈칸으로 읽는다. 「계산값: … 넣지 못했다」가 나오면 결과에 적는다.
3. `python scripts/xlsx_tool.py verify <템플릿> <결과>` — 시트 · 병합 · 열 너비 · 표시 형식 · 그림을 견준다. 그리고 아래 둘을 보인다.
   - **글자가 된 숫자**: 템플릿에서 숫자였던 칸에 숫자 모양 글자가 들어간 곳. 숫자로 다시 넣는다.
   - **견본 수치**: 템플릿과 같은 수가 남은 칸. 이번 자료의 값으로 바꾼다. 템플릿이 지난 판이면 「바꾸지 않은 수」 목록이다.
4. `python ../../scripts/render.py <결과> <새 빈 폴더>` 로 인쇄 쪽 그림을 만들고 Read 로 본다. 잘린 글 · `####` 칸 · 넘친 열이 있으면 고친다.
   템플릿에 원래 잘린 행이 있으면 `fit_rows` 로 시트 전체의 행 높이를 맞춘다.

```json
{"ops": [
  {"set": "집계!B2", "value": 12},
  {"set": "집계!C2", "value": {"date": "2026-10-29"}},
  {"set": "집계!B10", "value": "=SUM(B2:B9)"},
  {"rows": "집계!A2", "values": [["접수", 12, {"date": "2026-10-29"}], ["회신", 8, {"date": "2026-10-30 14:30"}]], "style_from": 2},
  {"clear": "집계!A12:C20"},
  {"fit_rows": "집계"}
]}
```

- 값은 JSON 그대로 들어간다. 숫자는 숫자로 넣는다 — `"12"` 로 넣으면 글자가 되어 합계 · 서식이 안 먹는다. `=` 로 시작하는 글은 수식이다. 코드 값(`"001"`)처럼 원래 글자인 칸은 글자로 둔다.
- 날짜는 `{"date": "YYYY-MM-DD"}` (시각까지면 `"YYYY-MM-DD HH:MM"`)로 넣는다. 날짜 서식이 없는 칸이면 그 칸 서식을 본떠 `yyyy-mm-dd` 를 붙인다.
- `rows` 는 칸부터 아래로 덮어 쓴다. 행을 끼우지 않는 까닭: 끼우면 병합 · 수식 범위 · 조건부 서식이 따라 밀리지 않아 표가 깨진다. 합계 행이 아래에 있으면 그 수식 범위를 `set` 으로 다시 쓴다.
- `style_from` 은 그 행의 칸 서식 · 행 높이를 본뜬다. 견본 표의 몸통 첫 행을 주면 된다. 채운 행이 엑셀 표(정렬 · 필터가 걸린 표) 밖으로 나가면 도구가 표 범위를 늘린다.
- 병합된 칸은 첫 칸(왼쪽 위)에 쓴다. 병합 안쪽 칸에 쓰면 도구가 멈춘다.
- 여러 칸이 함께 쓰는 공유 수식의 기준 칸은 바꾸지 못한다(도구가 멈춘다). 사용자에게 알린다.
- 견본에만 있던 값은 `clear` 로 지운다.

## 템플릿이 없을 때

`python scripts/xlsx_tool.py new <spec> <결과>` — 첫 행을 머리글로 굵게 하고 틀을 고정한다(`"header": false` 로 끈다). 만든 뒤에도 4를 한다.

```json
{"sheets": [{"name": "집계", "rows": [["구분", "건수", "일자"], ["접수", 12, {"date": "2026-10-29"}]], "widths": [14, 10, 12]}]}
```

## 지킬 것

- 템플릿에 덮어쓰지 않는다. 결과 경로에 파일이 있으면 도구가 멈춘다.
- 수치를 지어내지 않는다. 근거가 된 코드 · 자료 위치를 결과에 적고, 모르는 칸은 비운다.
- 글꼴 · 글자 크기 · 열 너비를 바꾸지 않는다. 넘치면 행 높이를 늘리거나(`fit_rows`) 글을 줄인다.
- 쪽 그림을 그리지 못했으면 결과에 「쪽 그림 확인을 못 했다」고 적는다.
