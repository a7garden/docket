# 워드 산출물

작업은 `scripts/docx_tool.py` 로 하고, 쪽 그림 확인은 플러그인 공용 `../../scripts/render.py` 로 한다(둘 다 이 SKILL.md 가 있는 폴더 기준. 다른 작업 폴더에서는 절대 경로로 부른다).
필요한 것: Python 3 · `python-docx`. 없으면 `python -m pip install python-docx` 를 알리고 멈춘다 — 다른 방법으로 우회하지 않는다.

## 템플릿이 있을 때 (먼저 고른다)

1. `python scripts/docx_tool.py inspect <템플릿>` 으로 자리와 지금 글자를 본다. 본문 문단 `p3` · 표 칸 `t0.r1.c2` · 글상자 `x0.p1` · 머리말 `h0.p0` · 꼬리말 `f0.p0`.
   칸 끝의 `[…]` 표시(병합 · 표 속 표 · 그림)를 먼저 읽는다.
2. 넣을 글(원고)을 다 정하고 다듬은 뒤 spec JSON 으로 시스템 임시 폴더에 쓴다. 파일에는 한 번만 넣는다 — 넣은 뒤 문장을 고치려고 다시 채우지 않는다.
3. `python scripts/docx_tool.py fill <템플릿> <spec> <결과>` — 템플릿은 건드리지 않고 사본을 만든다.
4. `python scripts/docx_tool.py verify <템플릿> <결과>` — 쪽 설정 · 스타일 · 표 구성을 견주고, **템플릿 글자가 그대로 남은 자리**를 보인다. 이름표 · 머리글이 아닌 견본 글자는 바꾸거나 지운다.
5. `python ../../scripts/render.py <결과> <새 빈 폴더>` 로 쪽 그림을 만들고 Read 로 열어 본다. 넘친 표 · 빈 쪽 · 어긋난 줄이 있으면 고쳐서 3부터 다시 한다(결과 이름은 새로 준다).

```json
{"ops": [
  {"replace": "p1", "find": "홍길동", "with": "산림재해연구과"},
  {"replace": "*", "find": "2026-001", "with": "2026-117"},
  {"set": "p4", "text": "본문 한 문단을 통째로\n바꾼다"},
  {"set": "t0.r1.c1", "text": "완료"},
  {"set": "t0.r1.c2", "text": ["여러 줄이면", "목록으로"]},
  {"set": "h0.p0", "text": "문서번호 2026-117"},
  {"add_row": "t0", "like": 2, "cells": ["통계", "진행", "-"]},
  {"insert_after": "p5", "like": "p5", "text": "같은 서식의 문단을 하나 더"},
  {"delete": "p9"}
]}
```

- **`replace` 를 먼저 고른다.** 「■ 작성자: 홍길동」처럼 한 문단에 굵은 이름표와 값이 섞여 있으면, 찾을 말만 바꿔야 이름표 서식이 남는다. `"*"` 는 문서 전체(표 · 글상자 · 머리말 포함)에서 모두 바꾼다. 못 찾으면 멈춘다.
- `set` 은 문단 · 칸을 첫 글자 묶음의 서식 하나로 통째로 바꾼다. 서식이 섞인 문단에 쓰면 그 서식이 사라진다.
- 세로 병합에서 이어지는 칸, 표 속 표는 쓰지 못한다(도구가 멈춘다). 병합이 시작하는 칸에 쓴다.
- 그림이 든 문단 · 칸에 `set` 을 쓰면 멈춘다. 글자만 바꿀 때는 `replace` 를 쓰고, 그림을 지워도 될 때만 `"drop_images": true` 를 준다.
- 글상자는 Word 가 두 번 적어 두는데(새 꼴 · 옛 꼴) 도구가 둘 다 고친다.
- `add_row` 는 `like` 번째 행(없으면 마지막 행)을 본떠 표 끝에 붙인다. 여러 번 부르면 적은 순서대로 이어진다.
- 견본에만 있던 문단 · 행은 `delete` 로 지운다.

## 템플릿이 없을 때

`python scripts/docx_tool.py new <spec> <결과>` — 블록 목록으로 만든다. 글꼴은 맑은 고딕 10.5pt 가 기본이다(`font` · `size` 로 바꾼다). 만든 뒤에도 4 · 5를 한다.

```json
{"blocks": [
  {"h1": "제목"}, {"p": "본문"}, {"bullets": ["가", "나"]}, {"numbers": ["하나", "둘"]},
  {"table": [["항목", "상태"], ["접수", "진행"]]}, {"page_break": true}
]}
```

## 지킬 것

- 템플릿에 덮어쓰지 않는다. 결과 경로에 이미 파일이 있으면 도구가 멈춘다 — 다른 이름을 준다.
- 도구가 다루지 못하는 개체(표 속 표 · 머리말 안 표 · 각주)를 지우거나 그림으로 바꿔 피하지 않는다. 그대로 두고 결과에 밝힌다.
- 사실(기관명 · 날짜 · 수치)을 지어내지 않는다. 모르는 칸은 비우고 결과에 적는다.
- 쪽 그림을 그리지 못했으면(render.py 가 까닭을 알린다) 결과에 「쪽 그림 확인을 못 했다」고 적는다.
